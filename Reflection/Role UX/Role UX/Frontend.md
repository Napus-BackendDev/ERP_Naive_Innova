## 1. Lessons Learned

Building an application with AI has changed the way I work as a Frontend Developer. AI helped me write code faster, fix errors, and understand new technologies more easily. It also helped me create UI components and improve the design more efficiently.

One thing that got better was **development speed**. I could use AI to generate code examples, suggest solutions, and reduce repetitive tasks. This gave me more time to improve the application's user interface (UI) and user experience (UX).

However, one thing that got worse was **becoming too dependent on AI**. Sometimes, the code generated by AI was not completely correct or did not match the project requirements. Therefore, I had to review, test, and understand the code carefully.

I also learned that code quality and security should not be ignored just because AI can generate code quickly. Teamwork and communication were important too, especially to make sure the frontend worked correctly with the backend.

## 2. Where I Stand in the Software Industry Today

In the AI era, I believe being a software developer is not just about writing code. We also need problem-solving skills, creativity, and the ability to use AI tools effectively.

As a Frontend Developer, I need to understand users' needs, design clear and attractive interfaces, and build applications that are easy to use.

I see AI as a useful assistant, not a replacement for developers. Developers still need to make decisions, check the quality of the code, and take responsibility for the final product.

## 3. My Plan for the Future

Next year, I plan to improve my frontend development skills, especially in React, JavaScript, TypeScript, and UI/UX design. I also want to gain practical experience through an internship and by working on projects with a team.

In the next five years, I hope to become a professional Frontend Developer who can build high-quality applications, collaborate confidently with a development team, and understand both frontend and backend systems.

My goal is to keep learning new technologies and use AI effectively as a tool to become a better software engineer.
